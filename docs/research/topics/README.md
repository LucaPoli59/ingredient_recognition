# Topic research

**Created:** 2026-08-02  
**Last updated:** 2026-08-02

Use this directory for detailed research on a single, well-defined topic.

```text
topics/
└── <topic>/
    ├── README.md
    └── <files>.md
```

Use a lowercase, descriptive directory name for `<topic>`. Its `README.md` must explain the topic's context, research scope, and the purpose and structure of the files it contains.
