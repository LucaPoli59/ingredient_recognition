# Research documentation

**Created:** 2026-08-02  
**Last updated:** 2026-08-02

This directory contains research records used to inform the Ingredient Recognition project. Store focused investigations in [`topics/`](topics/README.md) and broad state-of-the-art scans in [`discovery/`](discovery/README.md).

Each `<topic>/` and `<discovery_date>/` subdirectory must contain its own `README.md`. That README must provide the context, scope, and file structure for the records in that subdirectory.
